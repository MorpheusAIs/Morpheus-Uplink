Disk space is low — free space below 2 GiB or 15% on a watched path.
Disk still full — reclaim Docker logs on host

Uplink cannot remove Docker container logs. To free space from rotated/fat json-file logs, recreate long-running containers (keeps volumes). Copy-paste on the host — never auto-run from the product: 

# SecretVM
docker compose -f docker-compose.secretvm.deployed.yml up -d --force-recreate --no-deps uplink proxy-router traefik

# Generic
docker compose -f docker-compose.generic.deployed.yml up -d --force-recreate --no-deps caddy uplink proxy-router
